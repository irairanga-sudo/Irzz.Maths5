About Irzz.Maths.LK

A Mathematics class built by a mathematician, run like software.

Irzz.Maths.LK is an English-medium online Mathematics class for Grades 6–11, founded to bring structured, exam-focused teaching to students wherever they are — with the same tracking and feedback a good in-person class gives you.

  • ✓ Full O/L syllabus coverage, grade by grade
  • ✓ Every test auto-marked with instant feedback
  • ✓ Notes, recordings and results in one dashboard
